# T1496 Resource Hijacking
Adversaries leverage compromised compute resources (EC2, containers, Lambda) to run unauthorized workloads, most commonly cryptocurrency mining, consuming CPU/network capacity and driving up cloud costs.
Mitigation: patch public-facing applications; least-privilege IAM roles; egress filtering to known mining-pool IPs/domains; budget/cost anomaly alerts.
Detection: GuardDuty CryptoCurrency findings; sustained high CPU utilization with no corresponding legitimate workload; DNS queries to known mining-pool domains; unexpected outbound connections on mining protocol ports (e.g., Stratum).
