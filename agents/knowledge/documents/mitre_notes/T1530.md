# T1530 Data from Cloud Storage
Adversaries access cloud storage objects (e.g., S3) to collect and exfiltrate data.
Mitigation: least-privilege bucket policies; Block Public Access; encryption; data-event logging.
Detection: anomalous GetObject volume; access to sensitive (Macie-classified) buckets.
