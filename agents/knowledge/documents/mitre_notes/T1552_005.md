# T1552.005 Cloud Instance Metadata API
Adversaries abuse the instance metadata service (IMDS) to steal EC2 role credentials (often via SSRF).
Mitigation: enforce IMDSv2; restrict egress; revoke and rotate exposed role credentials and STS sessions.
Detection: role credentials used from an IP outside the instance (GuardDuty InstanceCredentialExfiltration).
